# Справочник ж/д станций ЕСР с координатами (пространство 1520)

Единый справочник всех кодов ЕСР из `data/raw/esr.csv` (26 644 кода) с координатами и аналитикой.
Координаты берутся из `data/raw/osm2esr.csv` (привязка к OpenStreetMap, 19 957 строк на 18 269 кодов).
Справочник готов для загрузки в HTML-дашборд с картой.

Пересборка: `pip install pandas numpy scipy rapidfuzz openpyxl && python3 scripts/build_stations.py`

## Результат (`data/output/`)

| Файл | Что внутри |
|---|---|
| `stations.csv` | все 26 644 кода ЕСР, одна строка на код; UTF-8 с BOM, разделитель `;` (открывается в Excel) |
| `stations.xlsx` | справочник с русскими заголовками и фильтрами, листы «Дубли OSM (разные места)», «Проверить (C)», «Без координат», сводки по странам, типам и дорогам, легенда, проверка интерполяции |
| `stations.geojson` | 24 891 точка для карты (Leaflet, MapLibre и т.п.), компактные свойства |
| `osm_candidates.csv` | все строки OSM с оценкой, отметкой выбранной и расстоянием до неё, для ручной проверки дублей |

## Качество координат

| Класс | Кодов | Как получено |
|---|---:|---|
| A — подтверждено | 17 395 (65,3%) | одна точка OSM (или все дубли в пределах 5 км), привязка подтверждена (`status=1`), название совпадает, точка рядом с соседними по номеру кодами |
| B — вероятно | 665 (2,5%) | выполнены 2 из 3 проверок, или выбрано из нескольких мест с уверенным отрывом по баллам |
| C — сомнительно | 209 (0,8%) | неподтверждённая привязка, другое название, далеко от соседей или неоднозначные дубли. Проверить вручную |
| D — по связанному коду | 1 976 (7,4%) | координаты основного кода станции (`dup_esr`: парки, стыки, САИПС) или одноимённой станции рядом с соседями по коду |
| E — оценка по соседям | 4 646 (17,4%) | линейная интерполяция между соседними по номеру кодами (приблизительно) |
| нет координат | 1 753 (6,6%) | данных нет |

Колонка `coord_precision_km` содержит ожидаемую точность: 0,5 км для A/B, 2–3 км для D, не меньше 10 км для E.
На карте классы стоит различать цветом и прозрачностью, а E (а по желанию и C) показывать с выключаемым слоем.

### Как выбирается точка из дублей OSM

Для каждого кандидата считается балл:

- `+2` подтверждённая привязка (`status=1`); `status=2` означает подбор по названию, такие точки часто
  привязаны сразу к нескольким кодам;
- `+1,5` в OSM стоит тег ЕСР с этим кодом (колонка `user`);
- `+3 × похожесть` названия (с учётом alt/old/official name). Если в названиях разные числа
  («158 км» и «138 км»), совпадение не засчитывается;
- `+0,5` тип совпадает (о.п. → `halt`, остальное → `station`); `+0,5` объект является точкой, а не контуром;
- `−1,5` тот же объект OSM привязан к другим кодам;
- `−1,5…−4,5` штраф за удалённость от соседних по номеру кодов ЕСР. Коды присваиваются вдоль линий,
  поэтому соседние номера почти всегда находятся рядом.

Выигрывает кандидат с максимальным баллом. Все альтернативы с баллами лежат в `osm_candidates.csv`.

### Проверка интерполяции (класс E)

Каждая точка класса A по очереди скрывалась и восстанавливалась по соседям, всего 15 973 проверки.
Медианная ошибка составила 3,9 км, 90-й перцентиль — 13,4 км. В заявленную точность попали 87,8% точек,
ошибку больше 30 км дали 1,5%. Для обзорной карты этого достаточно, для точной геопривязки нет.

## Аналитика в справочнике (основные колонки)

- Коды: `esr`, `esr5` (без контрольной цифры, для стыковки с системами на 5-значных кодах),
  `esr_check_ok` (проверка контрольной цифры), `dup_esr` (основной код станции), `express` (Экспресс-3).
- Название: `name`, `name_clean` (без пометок в скобках), `name_note`, признаки `is_km_name`,
  `is_virtual` (узлы, условные коды), `is_export` («эксп.»), `is_transship` («перев.»),
  `is_narrow_gauge` («УЗК»), `is_foreign`.
- География: `country` / `country_iso` (из справочника ЕСР; если пусто, то из ISO региона), `region`, `region_iso`,
  `railway`, `division`. `admin_inferred` перечисляет поля, достроенные по 7 ближайшим станциям
  (не дальше 50 км, нужно не меньше 4 единогласных соседей). Так заполнены 2 924 записи.
- Тип: `type` и `type_source` (ЕСР / OSM / по названию).
- Координаты: `lat`, `lon`, `coord_quality`, `coord_source`, `coord_precision_km`, `coord_note`
  (причины понижения класса), `geo_country_mismatch`.
- OSM: `osm_id`, `osm_type`, `osm_url`, `osm_name` и альтернативные названия, `osm_name_sim`, `nbr_dist_km`,
  `osm_candidates`, `osm_places`, `osm_spread_km`, `choice_margin`.

Примечание: `country` в справочнике ЕСР отражает принадлежность дороге, а не только территорию.
Например, часть станций в Казахстане числится за российскими дорогами. Где это расходится с ISO
региона, стоит флаг `country_iso_conflict`.

## Ограничения и что можно улучшить

- Внешние источники (Overpass API OSM, Wikidata) из среды сборки были недоступны. Если сеть есть,
  оставшиеся 1 753 кода и класс E можно уточнить: выгрузить из OSM объекты `railway=station|halt`
  с тегами `esr:user` / `railway:ref` и названиями и прогнать через тот же скрипт.
- Интерпретация пометок («эксп.», «перев.», «УЗК») выведена из названий, а не из официального описания.
