# Справочник ж/д станций ЕСР с координатами (пространство 1520)

Единый справочник всех кодов ЕСР из `data/raw/esr.csv` (26 644 кода) с координатами и аналитикой.
Координаты берутся из `data/raw/osm2esr.csv` (привязка к OpenStreetMap, 19 957 строк на 18 269 кодов).
Справочник обогащён данными ТР №4 (тарифный список станций), АСУ «Экспресс» и таблицей перекодировки
станций Крыма. Он готов для загрузки в HTML-дашборд с картой.

| Источник (`data/raw/`) | Что даёт |
|---|---|
| `esr.csv` | основа: коды ЕСР, названия, страна, регион, дорога, отделение, тип, код Экспресс |
| `osm2esr.csv` | координаты из OpenStreetMap (с дублями) |
| `tr4_stations_rf.xls`, `tr4_stations_sng.xls` | открытые данные «ТР №4, кн. 2, ч. 1. Алфавитный список ж/д станций» на 30.12.2023: признак действующей тарифной станции, пассажирские и грузовые операции, владелец инфраструктуры, транзитные пункты с тарифными расстояниями, бывшие названия |
| `express.csv` | названия АСУ «Экспресс», сокращение дороги, городские коды (МОСКВА 2000000 и т.п.) |
| `crimea.csv` | старый код УЗ ↔ новый код станций Крыма |
| `tr4_book1_2026-10-21.xls` | ТР №4 на 21.10.2026, Книга 1: 2 179 тарифных участков, станции по порядку и километраж. По ним ставятся станции без координат и проверяются существующие |
| `tr4_book2_2026-10-21.xls` | ТР №4 на 21.10.2026, Книга 2: действующие раздельные (РП) и остановочные (ОП) пункты, города, порты перевалки. Заменяет список 2023 года, тот оставлен только для отметки исключённых станций |
| `osm_esr_fresh.csv` | свежая выгрузка OpenStreetMap (объекты с тегом `esr:user`, © участники OpenStreetMap, ODbL) — для сверки координат; дата — в `sources_meta.json` |
| `osm_stations_named.csv` | все станции и платформы OSM с названиями в регионе 1520 (ODbL) — поиск станций без координат по названию |
| `wikidata_esr.csv` | Викиданные: станции с кодом ЕСР (P2815) и координатами (CC0) — для сверки координат |
| `tr4_book3_2026-10-21.xls` | ТР №4 на 21.10.2026, Книга 3: расстояния между транзитными пунктами (не используется) |

Пересборка: `pip install pandas numpy scipy rapidfuzz openpyxl xlrd && python3 scripts/fetch_sources.py && python3 scripts/build_stations.py`
(`fetch_sources.py` нужен интернет; без него сборка использует уже сохранённые выгрузки из `data/raw/`)

## Брендбук (`brand/`)

Проект называется **RWS 1520** (Railway Stations 1520). Визуальный стиль задан брендбуком `brand/BRANDBOOK.md`:
- `tokens.css` — цветовые токены светлой и тёмной темы;
- `map-colors.js` — цвета слоёв карты;
- `logo/` — знак, favicon и локап.

Главные правила: синий — бренд и справочник, оранжевый — только данные пользователя (вагоны), категории
карты — отдельная палитра. У «только пассажирских» станций различие продублировано формой (кольцо).

## Дашборд-карта (`dashboard/rws1520_v3.1.html`)

Один самодостаточный HTML-файл (~15 МБ: данные, библиотеки, офлайн-схема и шрифты встроены): открывается двойным щелчком или кладётся
на любой статический хостинг (GitHub Pages, S3, nginx). Пересборка после обновления справочника:
`python3 scripts/build_dashboard.py` (шаблон — `dashboard/template.html`).

- **Карта**: MapLibre GL (WebGL, все 25 тыс. точек без кластеризации). Бесплатные подложки без ключей:
  OpenFreeMap (светлая и подробная векторные), CARTO Dark Matter, спутник Esri World Imagery, OpenStreetMap.
  Поверх можно включить слой OpenRailwayMap: инфраструктура, максимальные скорости, электрификация, ширина колеи.
- **Поиск** по названию (без учёта регистра и «ё», по нескольким словам, также по названиям «Экспресс»,
  бывшим названиям и названиям OSM), по коду ЕСР или его началу, коду «Экспресс», старому коду Крыма.
  Работает с клавиатуры: `/` — фокус, стрелки, Enter, Esc.
- **Карточка станции**: коды с копированием в один клик, координаты, класс точности и круг погрешности на
  карте, справочные поля, данные ТР №4, связанные коды (основной, Крым), 6 ближайших станций. Есть ссылки
  на Яндекс Карты, OpenRailwayMap и объект OSM. Ссылку на станцию можно отправить: `rws1520_v3.1.html#esr=060073`.
- **Фильтры**: точность координат, страна, дорога, регион, тип пункта, наличие в ТР №4, пассажирские и
  грузовые операции. Для каждого значения показано число станций.
- **Раскраска точек**: по точности, типу пункта, операциям ТР №4, дороге или стране, с легендой и счётчиками.
- **Выгрузка**: CSV (UTF-8, `;`, открывается в Excel) и XLSX по всему справочнику или по текущему фильтру,
  GeoJSON для ГИС. Станции без координат тоже попадают в CSV/XLSX.
- Светлая и тёмная тема (по системе или вручную).
- **Панель можно скрыть** кнопкой в её шапке и вернуть кнопкой «Поиск и фильтры»; состояние запоминается.
  На телефоне панель — выдвижная шторка: стартует свёрнутой, свайп вверх разворачивает, свайп вниз сворачивает
  и прячет её совсем. Касание пустого места на карте сворачивает шторку. При выборе станции панель открывается сама.
- **Зона погрешности.** У выбранной станции с погрешностью от 2 км на карте рисуется пунктирный круг с подписью
  «зона ±N км»; карта приближается так, чтобы круг был виден целиком. В карточке есть пояснение и переключатель,
  тот же переключатель есть в «Слоях».
- **Схема тарифных участков** (линии между станциями) по умолчанию выключена. Включается в легенде или в «Слоях».

### Вкладка «Вагоны»: отчёт по вагонному парку или любая таблица «вагон — станция» на карте

Отчёт из системы управления вагонным парком загружается кнопкой или перетаскиванием на карту.
Поддерживаются Excel (.xlsx, .xls) и CSV. Файл разбирается только в браузере и никуда не отправляется,
в репозиторий отчёты не кладутся.

- **Универсальный загрузчик.** Подходит отчёт по дислокации или любая таблица, где есть станция:
  - «№ вагона; код станции», в том числе без строки заголовков;
  - станция названием вместо кода;
  - сводка «станция; количество» — тогда вагоны считаются как сумма по числовому столбцу;
  - ячейки, скопированные из Excel (Ctrl+V на вкладке).

  Шаблон CSV скачивается с экрана загрузки.
- Строка заголовков находится автоматически, служебные строки над ней («Сформирован…», фильтры) пропускаются.
- Если в заголовках есть «станция … код» (как в дислокации), берутся только эти столбцы. Иначе столбец со
  станцией определяется по содержимому. При заголовке вида «Станция», «Пункт», «ЕСР» достаточно 30% распознанных
  значений, в остальных случаях нужно 60%; годы, пробеги, страны и дороги не учитываются. Любой столбец можно
  назначить станцией вручную.
- Названия станций сопоставляются однозначно. При тёзках выводится подсказка «несколько станций с таким
  названием — укажите код ЕСР».
- Столбцы с кодами станций — те, где в заголовке есть «станция» и «код»: «Станция операции (код)»,
  «Код станции отстоя», «Станция приписки (код)» и т.д. Переключатель «Станция на карте» выбирает,
  по какому из них раскладывать вагоны (например, неизменная приписка или меняющийся отстой). У каждого
  варианта показано, у скольких вагонов он заполнен.
- Коды сопоставляются со справочником ЕСР. Если Excel съел ведущие нули или код записан без контрольной
  цифры, он всё равно распознаётся. Коды, которых нет в справочнике, и станции без координат
  перечислены в блоке «Не показаны на карте».
- **Считать** (раздел сворачивается): действие и столбец — «1 строка = 1 вагон» (по умолчанию), уникальных
  значений (например, уникальных вагонов), заполненных строк, сумма, среднее, минимум, максимум. Для суммы
  и среднего предлагаются только числовые столбцы-величины (коды, номера, годы и месяцы — нет). Размер кружков,
  подписи, рейтинг, легенда и сводка CSV — по выбранной мере; доли — только у складываемых мер.
- **Фильтры по отчёту** (раздел сворачивается, в заголовке — сколько фильтров активно): по любым столбцам.
  По умолчанию предложены «Род ПС», «Состояние», «ГРУЖ/ПОР» и «Подход», остальные добавляются из списка,
  лишние убираются крестиком. Есть и поиск по номеру вагона.
- Отображение: кружки, размер которых пропорционален мере, или тепловая карта; переключатель слоя
  предприятий ремонта (и расстояний до них в рейтинге).
- **Рейтинг** по станциям, дорогам, регионам или странам. У дороги, региона, страны раскрываются её станции,
  карта приближается к ним, остальные кружки приглушаются.
- **Сводка (CSV)** — на уровне текущей группировки и по выбранной мере: строк отчёта, значение, доля, нарушения;
  у станций — координаты, дорога, регион, страна и ближайшее предприятие ремонта.
- В карточке станции видно, сколько вагонов относится к ней по каждому столбцу, разбивка по первому
  фильтру и список вагонов. Вагоны станции можно выгрузить в CSV со всеми столбцами отчёта,
  а сводку по станциям — с координатами.

#### Ограничения курсирования (в разработке, только в пробной сборке)
Отложено до реальных данных о договорах лизинга. В рабочей сборке выключено; пробная сборка:
`python3 scripts/build_dashboard.py --preview` → `dashboard/rws1520_v<версия>_preview.html` (в git не хранится).

Если в отчёте есть столбец с перечнем регионов по договору лизинга — «Запрещённые регионы», «Ограничения
курсирования», «Разрешённые регионы» или «Полигон курсирования», — дашборд проверяет каждый вагон:
- **Перечень.** Элементы разделяются «;» или «,». Это регионы (можно коротко: «Дагестан», «Крым»), дороги («Забайкальская ж. д.»)
  или страны. Элемент сверяется с регионом, дорогой и страной станции, где стоит вагон.
- **Смысл перечня.** «Запрещённые» — нарушение, если станция в одном из регионов перечня. «Разрешённые» и «полигон» — нарушение,
  если станция вне всех регионов перечня. Столбец и смысл можно поменять вручную.
- **Карта.** Запретные зоны заштрихованы; регионы, где есть нарушения, выделены и подписаны числом вагонов.
  Станции с нарушениями — красные и поверх остальных; на тепловой карте — отдельные красные точки.
- **Панель.** Итог: вагоны, станции и регионы с нарушениями; переключатель «Только вагоны с нарушениями»;
  список регионов (щелчок приближает карту); выгрузка нарушений в CSV.
- **Карточка станции.** Вагоны с нарушением — первыми, с причиной.
- **Справка о нарушениях** — для отчёта перед лизинговыми компаниями. Отдельная справка на каждого получателя: столбец
  выбирается (по умолчанию «Лизингодатель», «Собственник» или «Договор»), получателей можно отметить. В справке:
  - шапка: отправитель, получатель, дата дислокации;
  - итог по запрещённым регионам и карта нарушений получателя;
  - перечень вагонов: № вагона, договор, род, состояние, станция, код ЕСР, регион, дорога, нарушенное ограничение,
    пустой столбец «Пояснение / принятые меры»;
  - итог, исполнитель, место для подписи.

  Форматы: **Excel** (лист «Сводка» и лист на каждого получателя, с автофильтром) и **печать / PDF**
  (A4 альбомная, каждая справка с новой страницы; в окне печати — «Сохранить как PDF»).
  Отправитель и исполнитель запоминаются.

Контуры регионов: `python3 scripts/build_region_shapes.py <папка с geojson Natural Earth 5.1.2>`.
Пример отчёта на случайных данных — `data/samples/дислокация_ограничения_пример.xlsx`
(генератор `scripts/make_restriction_sample.py`, число вагонов — вторым параметром; на 60 тыс. вагонов загрузка около 3 с).

Библиотеки MapLibre GL 4.7.1 и SheetJS 0.18.5 встраиваются в файл при сборке из `dashboard/vendor/`
(лицензии лежат там же), поэтому дашборд не зависит от CDN и открывается в сетях, где они заблокированы.
Из интернета берутся только подложки карты и шрифт. Если подложка недоступна (сайт заблокирован или нет сети),
дашборд сам переключается на **офлайн-схему**: суша, моря и границы государств Natural Earth 1:50m
(общественное достояние), встроены в файл, около 0,5 МБ. Эту схему можно выбрать и вручную в «Слоях».
На схеме подписаны по-русски страны, моря, крупные озёра и около 2 тыс. городов (Natural Earth 5.1.2,
ранжированы по населению и масштабу), есть реки и озёра. С масштаба 7,5 подписываются станции:
они обычно названы по посёлку. Шрифт при недоступности заменяется системным. Пересборка офлайн-схемы:
`npm i world-atlas@2.0.2 topojson-client@3.1.0 && node scripts/build_offline_basemap.mjs`;
подписи, вода, регионы, городские территории и дороги:
`python3 scripts/build_offline_labels.py <папка с geojson Natural Earth 5.1.2>`.

На офлайн-схеме есть:
- **регионы:** границы и названия 450 областей, краёв и республик стран 1520;
- **городские территории:** заливкой;
- **дороги:** магистрали и основные дороги.

### Предприятия ремонта вагонов и ближайшее предприятие по сети
- **Данные.**
  - `data/raw/sja_1001_17.csv` — СЖА 1001 17 «Условные коды предприятий», 2017 г.: код, наименования, код станции,
    виды ремонта. Разбор PDF: `python3 scripts/parse_sja.py <PDF>`.
  - `data/raw/zel_dor_depo.csv` — справочник кодов депо (свежие названия).
  - `data/raw/depots_manual.csv` — необязательные ручные уточнения: `code;esr;lat;lon;note`.
  - Сборка `python3 scripts/build_depots.py` → `data/output/depots.csv` и список ненайденных `depots_unplaced.csv`.
- **Граф сети.** `python3 scripts/build_rail_graph.py` → `data/output/rail_graph.json`: тарифные участки ТР №4,
  стыковка кодов одной станции и пограничных переходов, сверка с тарифными расстояниями. В цепочки участков
  не входят экспортные и перевалочные коды, узкоколейки и строки, не согласующиеся с километражом.
  Оборванные стыки (участок кончается пунктом стыка, а соседний начинается другим кодом; «Кама — Солдатка» без
  связующего участка до Дружинино) и пограничные переходы между экспортными пунктами («Красное (эксп.)» —
  «Осиновка (эксп.)») связываются; известные «несвязи» (Абхазия, Шарур — Ерасх, Заволжск — Кинешма) — в `NO_LINK`.
- **Главные магистрали.** `python3 scripts/build_mainlines.py` (после графа) → `data/output/mainlines.csv`.
  Широтные: Транссиб, Южный ход Транссиба, Казанский ход, БАМ, Южсиб, Турксиб, Среднесибирская, Северный широтный ход
  (действующие участки), Северный коридор ТАЖМ, Средний коридор (ТМТМ), Транскаспийская. Меридиональные: Москва —
  Санкт-Петербург, Печорская, Москва — Ростов — Кавказ, АЯМ, Север — Юг (восточный маршрут). Магистраль задана
  опорными станциями в скрипте, ход между ними — кратчайший путь по графу; длины сверяются с известными (Транссиб
  9 297 км по ТР №4 при справочных 9 289, БАМ 4 280 при 4 287, Москва — Санкт-Петербург 650), перегоны с большим
  объездом печатаются как «ВНИМАНИЕ». На карте — «Раскраска точек» → «Широтные магистрали» / «Меридиональные
  магистрали», фильтр «Магистраль», строка в карточке станции (км от начала магистрали), столбец в выгрузке.
- **Ручные координаты станций** — `data/raw/stations_manual.csv` (`esr;lat;lon;source;note`), приоритет над всеми
  источниками; для станций, которых нет в OSM с кодом ЕСР.
- **На карте.** Значки по `brand/depots/DEPOTS.md`. Быстрое включение — на боковой панели («На карте»), тип
  предприятия и вид ремонта — в «Слоях».
  Клик по значку — карточка предприятия.
- **Ближайшее предприятие** ищется по сети, среди предприятий страны станции:
  - в карточке станции — 3 ближайших;
  - во вкладке «Вагоны» — ближайшее у каждой станции списка и в «Сводке по станциям».

### Своя подробная карта из файла (PMTiles)

Полноценная карта OpenStreetMap (улицы, деревни, дороги, подписи по-русски) открывается из файла `.pmtiles`
на ПК или сетевом диске: «Слои» → «Открыть файл PMTiles». Файл читается частями, поэтому интернет и сервер
не нужны, а гигабайтный файл открывается быстро. Шрифты подписей (Noto Sans) и стиль Protomaps встроены
в дашборд. В Chrome файл запоминается: при следующем открытии достаточно нажать «Подключить снова».

Как получить файл (один раз, на ПК с интернетом):
1. Скачать утилиту `pmtiles` (github.com/protomaps/go-pmtiles → Releases).
2. Выбрать сборку на maps.protomaps.com/builds и вырезать область сети 1520:
   `pmtiles extract https://build.protomaps.com/20261020.pmtiles sng.pmtiles --bbox=19,35,180,78 --maxzoom=12`.
   Ориентировочно: `maxzoom=10` даёт сотни мегабайт (города и дороги), 12–13 — единицы гигабайт (улицы и деревни).
3. Положить файл на сетевой диск.

Поддерживаются векторные сборки Protomaps (в том числе старой схемы v3) и растровые `.pmtiles`;
`.mbtiles` конвертируется командой `pmtiles convert`. Стиль пересобирается командой
`node scripts/build_protomaps_style.mjs`. Лицензии компонентов перечислены в `dashboard/vendor/LICENSES.md`.

Если страница не открывается, вместо вечной «Загрузки данных…» появляется сообщение с причиной.
Чаще всего это отключённый в браузере WebGL: аппаратное ускорение выключено или страница открыта
через удалённый рабочий стол или виртуальную машину. Сообщение подсказывает, как это проверить
(`chrome://gpu`) и исправить.

### Как выбирается точка из дублей OSM

Для каждого кандидата считается балл:

- `+2` подтверждённая привязка (`status=1`); `status=2` означает подбор по названию, такие точки часто
  привязаны сразу к нескольким кодам;
- `+1,5` в OSM стоит тег ЕСР с этим кодом (колонка `user`);
- `+3 × похожесть` названия (с учётом alt/old/official name). Если в названиях разные числа
  («158 км» и «138 км»), совпадение не засчитывается;
- `+0,5` тип совпадает (о.п. → `halt`, остальное → `station`); `+0,5` объект является точкой, а не контуром;
- `−1,5` тот же объект OSM привязан к другим кодам;
- `−1,5…−4,5` штраф за удалённость от соседних по номеру кодов ЕСР. Коды присваиваются вдоль линий,
  поэтому соседние номера почти всегда находятся рядом.

Выигрывает кандидат с максимальным баллом. Все альтернативы с баллами лежат в `osm_candidates.csv`.

### Сверка со свежим OSM и Викиданными
`python3 scripts/fetch_sources.py` выгружает в `data/raw/` свежий OpenStreetMap (объекты с тегом `esr:user`, Overpass API)
и Викиданные (код ЕСР P2815); сборка сверяет с ними каждую точку (`scripts/verify_sources.py`):
- **подтверждено** — источник в пределах max(3 км, заявленной точности); оценки C и E при этом **уточняются** точкой
  источника и становятся B;
- **заменено** — оба источника согласны между собой (≤ 3 км), а точка справочника дальше 5 км; оценка E заменяется
  и по одному источнику с тем же названием;
- **добавлено** — код без координат: оба источника согласны — A, один с тем же названием — B;
- **расхождение** — больше 5 км и не решено большинством: точка не меняется, код попадает в
  `data/output/review_coordinates.csv` для ручной проверки.

Названия сравниваются и через транслитерацию. Новые и заменённые точки должны попасть в свой регион (запас 20 км).
Коды, оставшиеся без координат, ищутся по названию среди всех станций и платформ OSM (`data/raw/osm_stations_named.csv`,
`scripts/name_match.py`): точка в своём регионе и согласуется с тарифным расстоянием до соседа по участку ТР №4 —
класс B; соседей с координатами нет — класс C; нечёткие совпадения и названия вида «43 км» — только с участком.
Яндекс Карты не используются: условия их API запрещают сохранять координаты.
Итоги — в `data/output/verification.json`, на листе «Сверка OSM и Викиданные» в `stations.xlsx` и в окне «О данных».

### Сверка с километражом участков ТР №4
Последний шаг сборки (`km_check` в `scripts/tr4_2026.py`). Положение каждой станции тарифного участка по километражу
между ближайшими станциями класса A (опоры сами согласуются с километражом: прямая между ними не длиннее пути, ≤ 80 км)
сравнивается с её координатами. Допуск — max(5 км, 30% расстояния между опорами), запас на изгибы линии.
- оценки C, D, E не на своём месте — переставляются на положение по участку (класс E);
- точки OSM и Викиданных (A, B): дальше max(20 км, расстояние между опорами) — переставляются (привязан одноимённый
  объект в другом месте: Гульбах был в 571 км, Восточная в Екатеринбурге — в 125 км), ближе — класс понижается до C.

Ручные уточнения не проверяются. В `stations.csv` — столбцы `km_check` и `km_check_dev`, в карточке станции — строка
«Километраж участка ТР №4», итоги — в окне «О данных». Сборка 27.10.2026: 17 931 станция в проверке, 99,1% согласуются,
85 переставлено, 76 понижено до C; подозрительных рёбер графа сети — 4 вместо 19.

### Узлы и крайние станции участков ТР №4
Станция без координат, у которой на участке есть точка с координатами только с одной стороны (узел, стыковой пункт,
парк), ставится по ближайшей такой точке, если та не дальше 3 км по участку. Если рядом есть вторая точка и путь
между ними почти прямой, оценка сдвигается по направлению участка на тарифное расстояние. Если станция — конец
нескольких участков, оценки усредняются с весом 1/расстояние². Класс E, точность ±(км до соседа + 1): километраж
ТР №4 целый. Точка должна попасть в регион станции по справочнику ЕСР (запас 20 км), иначе станция не ставится:
так отсеиваются соседи с ошибочными координатами. Проверка на 6 225 известных точках: медианная ошибка 1,25 км,
90% — в пределах заявленной точности.

### Сверка с тарифными расстояниями ТР №4

Прямое расстояние от станции до её транзитного пункта не может заметно превышать тарифное (по путям).
Проверяется условие «прямая ≤ тариф × 1,1 + 10 км». Нулевые расстояния (пункт входит в узел) не проверяются.
В самом ТР №4 есть ошибки: например, у белорусских станций указан «Санкт-Петербург-Тов.-Витебский».
Поэтому флаг `transit_conflict` ставится, только если точка расходится со всеми своими транзитными
пунктами, а их не меньше двух. Оценки класса E с таким флагом сняты (7 шт.). Сейчас флаг стоит
у 14 точек (A — 2, B — 3, C — 7, D — 2).

### Проверка интерполяции (класс E)

Каждая точка класса A по очереди скрывалась и восстанавливалась по соседям, всего 15 973 проверки.
Медианная ошибка составила 3,9 км, 90-й перцентиль — 13,4 км. В заявленную точность попали 87,8% точек,
ошибку больше 30 км дали 1,5%. Для обзорной карты этого достаточно, для точной геопривязки нет.

## Аналитика в справочнике (основные колонки)

- Коды: `esr`, `esr5` (без контрольной цифры, для стыковки с системами на 5-значных кодах),
  `esr_check_ok` (проверка контрольной цифры), `dup_esr` (основной код станции), `express` (Экспресс-3).
- Название: `name`, `name_clean` (без пометок в скобках), `name_note`, признаки `is_km_name`,
  `is_virtual` (узлы, условные коды), `is_export` («эксп.»), `is_transship` («перев.»),
  `is_narrow_gauge` («УЗК»), `is_foreign`.
- География: `country` / `country_iso` (из справочника ЕСР; если пусто, то из ISO региона), `region`, `region_iso`,
  `railway`, `division`. `admin_inferred` перечисляет поля, достроенные по 7 ближайшим станциям
  (не дальше 50 км, нужно не меньше 4 единогласных соседей). Так заполнены 2 924 записи.
- Тип: `type` и `type_source` (ЕСР / ТР №4 / OSM / по названию).
- Крым: `esr_crimea_old` (у нового кода указан старый код УЗ) и `esr_crimea_new` (у старого кода указан новый).
- Экспресс: `express_name` (название в АСУ «Экспресс»), `express_railway` (сокращение дороги),
  `express_city` (городской код, например все вокзалы Москвы → `2000000 МОСКВА`).
- ТР №4: `in_tariff_list` (станция есть в действующем тарифном списке; 21 356 кодов), `tr4_list` (РФ / СНГ и Балтия),
  `tr4_name`, `tr4_former_name` (бывшее название), `tr4_point_type`, `tr4_owner` (дорога или частный
  владелец: ФГУП «КЖД», ЖДЯ, ООО «Рубикон», ЮКЖД), `tr4_pass_ops` + `tr4_pass_ops_label`, `tr4_passenger_open`,
  `tr4_freight_paragraphs` (параграфы грузовых операций как в ТР №4, например `1,3,8Н`), `tr4_freight_open`,
  `tr4_transit`, `tr4_transit_nearest`, `tr4_transit_nearest_km`, `tr4_comment`.
  Если в ЕСР дорога пустая, она берётся из ТР №4 (`railway_from_tr4`).
- Сверка с тарифом: `transit_checks`, `transit_violations`, `transit_conflict`.

Пассажирские коды ТР №4: **П** — продажа билетов на все поезда, приём и выдача багажа; **Б** — то же
без багажа; **О** — посадка и высадка на пригородные и местные поезда без багажа; **Х** — грузовые и
коммерческие операции не производятся; **К** — контрейлерные отправки. Номера грузовых параграфов
(1, 2, 3, 4, 5, 8Н, 9, 10Н…) оставлены как в источнике. Полную расшифровку нужно сверить с действующей
редакцией ТР №4 (кн. 2, ч. 1, табл. 1), её текст из среды сборки был недоступен.
- Координаты: `lat`, `lon`, `coord_quality`, `coord_source`, `coord_precision_km`, `coord_note`
  (причины понижения класса), `geo_country_mismatch`.
- OSM: `osm_id`, `osm_type`, `osm_url`, `osm_name` и альтернативные названия, `osm_name_sim`, `nbr_dist_km`,
  `osm_candidates`, `osm_places`, `osm_spread_km`, `choice_margin`.

Примечание: `country` в справочнике ЕСР отражает принадлежность дороге, а не только территорию.
Например, часть станций в Казахстане числится за российскими дорогами. Где это расходится с ISO
региона, стоит флаг `country_iso_conflict`.

## Ограничения и что можно улучшить

- Внешние источники (Overpass API OSM, Wikidata) из среды сборки были недоступны. Если сеть есть,
  оставшиеся 1 592 кода и класс E можно уточнить: выгрузить из OSM объекты `railway=station|halt`
  с тегами `esr:user` / `railway:ref` и названиями и прогнать через тот же скрипт.
- Интерпретация пометок («эксп.», «перев.», «УЗК») выведена из названий, а не из официального описания.
