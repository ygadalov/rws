# История версий RWS 1520

Правила нумерации: мелкая доработка — +0.1 (1.0 → 1.1 … 1.9 → 2.0), крупная — сразу следующая целая версия.
Текущая версия — в файле `VERSION`; собранный дашборд — `dashboard/rws1520_v<версия>.html`.

## 2.1 — 25.10.2026

- Боковая панель, вкладка «Станции»: раздел «На карте» с переключателем «Предприятия ремонта вагонов» (синхронен
  с «Слоями»); в подсказке (i) — что виды предприятий и вид ремонта настраиваются в «Слоях».
- Фильтр предприятий: «Локомот., пасс.» → «ТЧ, ТЧПРИГ, ЛВЧД», расшифровка — во всплывающей подсказке.
- Исправлено: Екатеринбург-Товарный (780302) стоял на точке ост. пункта Звезда — в старой выгрузке OSM код был
  на этой точке, в свежем OSM исправлен на 780904. Сборка теперь отбрасывает такие устаревшие привязки (5 кодов);
  для Екатеринбург-Товарного — ручные координаты по OSM «Товарный двор СвЖД» (`data/raw/stations_manual.csv` —
  новый файл ручных уточнений, приоритет над всеми источниками).
- Граф сети: проверка всех расстояний «станция — предприятие» между надёжными точками (по сети не может быть
  короче, чем по прямой) нашла «короткие замыкания» — 338 тыс. невозможных пар, в основном Украина и Крым.
  Причины и исправления: экспортные и перевалочные коды, приписанные в книге 1 к участкам списком с 0 км
  («Плотина — Ост. пункт 6 км»: Керчь-Порт (эксп.), Севастополь-Товарный (эксп.)…), — исключены из цепочек (266);
  узкоколейные линии — исключены; строки участков, не согласующиеся с километражом, — убраны (34); коды,
  повторно использованные в разных местах, разделяются по положению на участке, а не только при удалении > 400 км;
  связи по основному коду, противоречащие участкам, пропущены (13); рёбра 0 км внутри узлов (МЦК, СПб) — по прямой.
  Осталось 349 пар у 79 станций предприятий — это неточные координаты отдельных станций, а не ошибки графа.
  Сверка с тарифными расстояниями ТР №4: точно 87% → 88%, в пределах 5% — 92% → 93%.

## 2.0 — 25.10.2026

**Предприятия ремонта вагонов на карте и ближайшее предприятие по сети**
- Справочник предприятий: СЖА 1001 17 «Условные коды предприятий» (2017; код станции и виды ремонта ТР/ДР/КР и др.,
  разбор PDF — `scripts/parse_sja.py`) + справочник кодов депо (свежие названия). `scripts/build_depots.py`:
  тип (ВЧДр, ВРЗ/ВРП, ВЧДЭ, ТОР/ПТО, прочие, локомотивные/пассажирские), владелец (ВРК-1/2/3, ОМК, НВК, РЖД…), место —
  станция примыкания (из СЖА, иначе из названия). На карте 1 454 предприятия; из дислокации на 5 805 вагонов —
  206 из 224 предприятий (90% записей). Ненайденные — `data/output/depots_unplaced.csv` и ручные уточнения
  `data/raw/depots_manual.csv`.
- Слой по `brand/depots/DEPOTS.md`: графитовая плашка с гаечным ключом (квадрат на обзоре), подписи с масштаба 10,
  бейдж числа вагонов на станции примыкания во вкладке «Вагоны»; несколько предприятий на станции — столбиком.
  «Слои» → «Предприятия ремонта вагонов»: включение, фильтр по типу и по виду ремонта (деповской, капитальный).
- Карточка предприятия: код, тип, владелец, виды ремонта, станция примыкания, сколько записей отчёта называют
  это предприятие в столбцах «Депо … (код)».
- Граф сети по тарифным участкам ТР №4 (`scripts/build_rail_graph.py`): 22,6 тыс. узлов, стыковка кодов одной станции,
  104 пограничных перехода (без Абхазии), разделение кодов, повторно использованных в далёких участках. Сверка
  с тарифными расстояниями ТР №4: 87% — точно, 92% — в пределах 5%.
- Карточка станции: 3 ближайших предприятия по сети (в своей стране). Вкладка «Вагоны»: ближайшее предприятие
  и расстояние у каждой станции в списке и в «Сводке по станциям (CSV)».
- Исправлено: клик по фильтру внутри меню «Слои» закрывал меню, если кнопка перерисовывалась.

## 1.5 — 24.10.2026

**Справочник станций: поиск станций без координат по названию**
- `fetch_sources.py` дополнительно выгружает все станции и платформы OSM с названиями в регионе 1520
  (`data/raw/osm_stations_named.csv`, 41 тыс. объектов; метро и городской транспорт исключены).
- Новый шаг `scripts/name_match.py`: станция без координат ищется по названию (все варианты названий, транслитерация,
  включая азербайджанскую латиницу). Совпадение принимается, если точка в своём регионе; если на участке ТР №4 есть
  соседи с координатами — расстояние по прямой должно согласоваться с тарифным (класс B), иначе — класс C.
  Нечёткое совпадение и названия вида «43 км» — только с подтверждением по участку.
- Координаты получили ещё 108 кодов (64 — класс B, 44 — класс C), больше всего в Азербайджане, Туркменистане
  и Беларуси. Без координат — 786 кодов (было 894).
- Яндекс Карты как источник не подключены: условия API запрещают сохранять координаты в свою базу.

## 1.3 — 24.10.2026

**Сверка координат со свежими внешними источниками**
- `scripts/fetch_sources.py` одной командой выгружает свежий OpenStreetMap (объекты с тегом `esr:user`, Overpass API,
  перебор зеркал) и Викиданные (код ЕСР P2815) в `data/raw/`.
- Новый шаг сборки `scripts/verify_sources.py`: точка подтверждается, если источник рядом; приблизительные оценки
  C и E при подтверждении уточняются точкой источника (класс B); точка заменяется, если оба источника согласны,
  а она дальше 5 км; коды без координат получают точку источника (оба согласны — A, один с тем же названием — B).
  Названия сравниваются и через транслитерацию (эстонские и литовские станции в источниках — латиницей).
  Новые и заменённые точки должны попасть в свой регион.
- Итог сверки 24.10.2026: подтверждено 18 736 точек (1 589 оценок уточнено), заменено 215, координаты получили
  169 кодов (без координат — 894 вместо 1 063), 218 расхождений — в списке `data/output/review_coordinates.csv`.
- Кочетовка I — 0,11 км до эталонной точки (было 0,8 км).

**Дашборд**
- В окне «О данных» — раздел «Сверка координат» с итогами и таблицей по классам.
- В карточке станции — результат сверки, расстояния до точек свежего OSM и Викиданных, ссылка на Викиданные.
- В выгрузках — столбцы сверки.

## 1.2 — 24.10.2026

**Справочник станций**
- Новый способ расстановки: станции без координат на краю тарифного участка ТР №4 (узлы, стыковые, парки) —
  по ближайшей точке участка не дальше 3 км, со сдвигом по направлению участка; если станция — конец нескольких

- Защита от ошибочных соседей: точка должна попасть в свой регион по справочнику ЕСР (запас 20 км), иначе не ставится.
- Координаты получили 23 станции, среди них Кочетовка I (ошибка 0,8 км до эталонной точки),
  Минск-Сортировочный, Тбилиси-Сортировочная, Рига-Краста, Одесса-Застава 1. Без координат — 1 063 кода вместо 1 086.
  Уже стоявшие координаты не менялись.
