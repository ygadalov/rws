# История версий RWS 1520

Правила нумерации: мелкая доработка — +0.1 (1.0 → 1.1 … 1.9 → 2.0), крупная — сразу следующая целая версия.
Текущая версия — в файле `VERSION`; собранный дашборд — `dashboard/rws1520_v<версия>.html`.

## 1.8 — 24.10.2026

- Кнопка темы: тёмная включалась только со второго клика — кнопка перебирала три режима («как в системе» →
  «светлая» → «тёмная»), и при светлой системной теме первый клик ничего не менял, а карта лишь перерисовывалась.
  Теперь каждый клик переключает светлую ↔ тёмную; если выбранная тема совпадает с системной — режим «как в системе».
  Значок показывает, что включится: луна — тёмная, солнце — светлая.

## 1.7 — 24.10.2026

- Строка поиска: подсказка «Название, код ЕСР (6 цифр) или Экспресс (7 цифр)» помещается целиком (панель шире
  на 16 px, отступы подстраиваются под пустую строку); на экранах уже 380 px — короткий вариант.
- Значок «/» в поиске: всплывающая подсказка «Нажмите / на клавиатуре — курсор сразу в поиске», клик ставит курсор
  в поиск; на сенсорных устройствах значок скрыт.
- Легенда «Раскраска точек» в свёрнутом виде: заголовок и стрелка по центру, стрелка показывает «развернуть».

## 1.6 — 24.10.2026

**Подсказки (i) — модуль info-tooltip**
- Все значки (i) переведены на собственный модуль подсказок (`dashboard/vendor/info-tooltip.*`, встраивается при сборке):
  общий слой поверх панелей, не обрезается, зажимается у краёв, переворачивается вверх; мышь, касание и клавиатура.
- «Точность координат» (i): расшифровка классов A–E прямо в подсказке (отдельное окно убрано).
- «О данных» (i) и «Своя карта из файла» (i): при наведении — короткая подсказка, по клику — окно с подробностями.
- Цвета подсказок — по брендбуку; исправлен шрифт подсказки (в модуле запись `font: … inherit` недопустима,
  браузер её отбрасывал и подсказка получала крупный шрифт страницы).

## 1.5 — 24.10.2026

**Справочник станций: поиск станций без координат по названию**
- `fetch_sources.py` дополнительно выгружает все станции и платформы OSM с названиями в регионе 1520
  (`data/raw/osm_stations_named.csv`, 41 тыс. объектов; метро и городской транспорт исключены).
- Новый шаг `scripts/name_match.py`: станция без координат ищется по названию (все варианты названий, транслитерация,
  включая азербайджанскую латиницу). Совпадение принимается, если точка в своём регионе; если на участке ТР №4 есть
  соседи с координатами — расстояние по прямой должно согласоваться с тарифным (класс B), иначе — класс C.
  Нечёткое совпадение и названия вида «43 км» — только с подтверждением по участку.
- Координаты получили ещё 108 кодов (64 — класс B, 44 — класс C), больше всего в Азербайджане, Туркменистане
  и Беларуси. Без координат — 786 кодов (было 894).
- Яндекс Карты как источник не подключены: условия API запрещают сохранять координаты в свою базу.

## 1.4 — 24.10.2026

- Регламент обновления `UPDATING.md`: периодичность (сверка с OSM и Викиданными — ежемесячно, остальные
  источники — по мере выхода), готовые промты для Claude Code, стоп-условия и что делать при сбоях.
- Ежемесячная плановая задача Claude Code (1-го числа) выполняет промт и открывает PR с отчётом; в `main` —
  только после проверки.

## 1.3 — 24.10.2026

**Сверка координат со свежими внешними источниками**
- `scripts/fetch_sources.py` одной командой выгружает свежий OpenStreetMap (объекты с тегом `esr:user`, Overpass API,
  перебор зеркал) и Викиданные (код ЕСР P2815) в `data/raw/`.
- Новый шаг сборки `scripts/verify_sources.py`: точка подтверждается, если источник рядом; приблизительные оценки
  C и E при подтверждении уточняются точкой источника (класс B); точка заменяется, если оба источника согласны,
  а она дальше 5 км; коды без координат получают точку источника (оба согласны — A, один с тем же названием — B).
  Названия сравниваются и через транслитерацию (эстонские и литовские станции в источниках — латиницей).
  Новые и заменённые точки должны попасть в свой регион.
- Итог сверки 24.10.2026: подтверждено 18 736 точек (1 589 оценок уточнено), заменено 215, координаты получили
  169 кодов (без координат — 894 вместо 1 063), 218 расхождений — в списке `data/output/review_coordinates.csv`.
- Кочетовка I — 0,11 км до эталонной точки (было 0,8 км).

**Дашборд**
- В окне «О данных» — раздел «Сверка координат» с итогами и таблицей по классам.
- В карточке станции — результат сверки, расстояния до точек свежего OSM и Викиданных, ссылка на Викиданные.
- В выгрузках — столбцы сверки.

## 1.2 — 24.10.2026

**Справочник станций**
- Новый способ расстановки: станции без координат на краю тарифного участка ТР №4 (узлы, стыковые, парки) —
  по ближайшей точке участка не дальше 3 км, со сдвигом по направлению участка; если станция — конец нескольких
  участков, оценки усредняются. Класс E, точность ±(км до соседа + 1).
- Проверка на 6 225 известных точках: медианная ошибка 1,25 км, 90% — в пределах заявленной точности.
- Защита от ошибочных соседей: точка должна попасть в свой регион по справочнику ЕСР (запас 20 км), иначе не ставится.
- Координаты получили 23 станции, среди них Кочетовка I (ошибка 0,8 км до эталонной точки),
  Минск-Сортировочный, Тбилиси-Сортировочная, Рига-Краста, Одесса-Застава 1. Без координат — 1 063 кода вместо 1 086.
  Уже стоявшие координаты не менялись.

## 1.1 — 24.10.2026

**Вкладка «Вагоны»**
- Список «Станции по числу вагонов» раскрывается целиком: под первыми 15 — строка «Остальные N ст. — M ваг. (X%)»
  и кнопки «Ещё 50» / «Все» (до 2000 станций; полный список — в сводке по станциям CSV).
- У каждой станции — доля от всех вагонов; числа выровнены.
- Кнопка у списка переименована: «Показать все» → «Все на карте» (она приближает карту, а не раскрывает список).
- Если кода станции нет в справочнике (например, условный код стыка «761800 Чепца»), станция берётся по названию
  из парного столбца отчёта; такие случаи перечислены в подсказке под выбором столбца.

## 1.0 — 24.10.2026

Первая версия с номером. Входит всё, что сделано до неё.

**Справочник станций**
- Единый справочник 27 476 кодов ЕСР с координатами и аналитикой: ЕСР, OpenStreetMap, ТР №4 (2023 и 21.10.2026),
  АСУ «Экспресс», перекодировка Крыма.
- Классы точности координат A–E, дедупликация кандидатов OSM, сверка с тарифными расстояниями ТР №4.

**Дашборд-карта**
- Поиск по коду, названию и коду Экспресс; фильтры; выгрузки CSV, Excel, GeoJSON.
- Карта сама приближается к отобранным фильтром пунктам; плитка «на карте» — кнопка «показать на карте».
- Работа в закрытых сетях: библиотеки встроены, офлайн-схема с подписями, своя карта из файла PMTiles.
- Скрываемая панель, отключаемые линии тарифных участков и круг точности, светлая и тёмная темы.
- Оформление по брендбуку RWS 1520.

**Вкладка «Вагоны»**
- Загрузка любого отчёта со станцией (код ЕСР или название): xlsx, xls, csv, вставка из Excel.
- Кружки или тепловая карта, фильтры по столбцам отчёта, поиск по № вагона, вагоны в карточке станции.
- Проверено на отчёте в 60 тыс. вагонов: загрузка около 3 с, остальные действия — доли секунды.

## В разработке (только в пробной сборке)

Отложено до получения реальных данных о договорах лизинга: формат столбцов и состав справки уточняются.
Код готов и выключен в рабочей сборке; пробная — `python3 scripts/build_dashboard.py --preview`.
- Ограничения курсирования по договору лизинга: запрещённые или разрешённые регионы, дороги и страны; запретные зоны
  на карте, станции с нарушениями, фильтр «только нарушения», выгрузка нарушений.
- Справка о нарушениях для лизинговых компаний: Excel и печать / PDF, отдельно на каждого получателя.
