              О данных

              Единый справочник станций с кодами ЕСР собран из справочника ЕСР и OpenStreetMap (osm2esr). Дополнительно использованы Тарифное руководство №4 на 21.10.2026 (Книга 1 — тарифные участки и расстояния, Книга 2 — списки станций, города и порты) и на 30.12.2023, АСУ «Экспресс» и перекодировка станций Крыма.

              Подложки: OpenFreeMap, CARTO, Esri World Imagery, OpenStreetMap; ж/д слой — OpenRailwayMap (CC-BY-SA). Данные карты © участники OpenStreetMap. Офлайн-схема — Natural Earth (общественное достояние).

              Своя подробная карта без интернета

              Дашборд может показывать полноценную карту OpenStreetMap (улицы, деревни, дороги, подписи) из файла .pmtiles, лежащего на вашем ПК или сетевом диске. Файл читается по частям — даже гигабайтный файл открывается быстро, интернет и сервер не нужны.

              Как получить файл (один раз, на ПК с интернетом):

              1. Скачайте утилиту pmtiles для своей системы: github.com/protomaps/go-pmtiles → Releases (для Windows — архив …Windows_x86_64.zip, внутри pmtiles.exe).
              2. Найдите свежую сборку карты мира на maps.protomaps.com/builds (файл вида 20261020.pmtiles).
              3. Вырежьте область сети 1520 командой:
                pmtiles extract https://build.protomaps.com/20261020.pmtiles sng.pmtiles --bbox=19,35,180,78 --maxzoom=12
                Утилита скачивает только нужную часть. Чем больше maxzoom, тем подробнее и тяжелее файл: ориентировочно 10 — сотни мегабайт (города и дороги), 12–13 — единицы гигабайт (улицы и деревни).
              4. Положите sng.pmtiles на сетевой диск — один файл для всех.
              5. В дашборде: «Слои» → «Открыть файл PMTiles». В Chrome файл запоминается: при следующем открытии достаточно нажать «Подключить снова».

              Подходят векторные сборки Protomaps (подписи по-русски, светлая и тёмная тема) и растровые .pmtiles. Файл .mbtiles можно преобразовать: pmtiles convert карта.mbtiles карта.pmtiles. Данные карты — © участники OpenStreetMap (ODbL).
