# RWS 1520 — слой «Вагоноремонтные депо» v1.0

Задача: показать на карте `rws1520.html` вагоноремонтные депо (ВРД) так, чтобы они не сливались со станциями. Дополняет брендбук (`rws1520-brand/BRANDBOOK.md`); если токены из `tokens.css` ещё не внедрены — код работает и без них (есть фолбэки).

| Файл | Что внутри |
|---|---|
| `DEPOTS.md` | Этот файл: правила отображения и задачи по внедрению |
| `depots-layer.js` | Готовый код слоя для MapLibre, разбит на пронумерованные блоки 1–8 |
| `depots.template.csv` | Шаблон данных по депо (разделитель `;`) |
| `icons/*.svg` | Значки: светлая/тёмная плашка 26 px и квадрат 10 px для мелкого масштаба |

---

## 1. Принцип

Станции — **цветные круги**. Депо отличается **формой** (скруглённый квадрат), **цветом** (графит — вне палитры станций, бренд-синего и оранжевого данных) и **пиктограммой** (гаечный ключ). Различие не зависит только от цвета — работает для дальтоников и на любой подложке.

## 2. Внешний вид

| Масштаб | Значок | Размер | Подпись |
|---|---|---|---|
| zoom < 6 — вся сеть | квадрат без пиктограммы | 8 px | нет |
| zoom 6–9 — регион | плашка с ключом | 20 px | нет |
| zoom ≥ 10 — узел | плашка с ключом | 26 px | название справа |

**Цвета**

| Подложка | Плашка | Ключ и обводка |
|---|---|---|
| Светлая (OSM, светлая векторная) | `#15181D` | `#FFFFFF` |
| Тёмная и спутник | `#E9ECF1` | `#0F1115` |

- Скругление плашки — 6 px при 26 px (≈ 23 %), обводка 2 px.
- **Подъездной путь:** пунктир от станции примыкания до депо, цвет ж/д линий (`#5B6F8F` / `#8FA4C4`), 1.5 px, видим с zoom 8. Рисуется только если у депо свои координаты.
- **Нет своих координат:** депо ставится на станцию примыкания со смещением значка на 14 px вправо-вниз, пунктира нет, в карточке пометка «положение приблизительное».
- **С вашими данными** (вкладка «Вагоны», данные загружены, zoom ≥ 6): справа от значка бейдж с числом — сколько записей на станции примыкания. Бейдж `#C2410C` (`--data-strong`), белый текст, обводка цвета подложки. Синий и оранжевый на самом значке депо не используются никогда.
- **Порядок слоёв (снизу вверх):** линии → пунктир депо → станции → вагоны → **депо** → выделение. Пересечения разрешены (`icon-allow-overlap`), депо не прячется за станцией.
- **Клик:** всплывающая карточка — название, владелец, станция примыкания (кнопка — выбирает станцию), число по вашим данным, примечание.
- **Слои и легенда:** переключатель «Вагоноремонтные депо» в панели «Слои» (сохраняется в `store`, по умолчанию включён); строка в легенде с квадратным значком и количеством.

## 3. Данные

Заполнить `depots.template.csv` (кодировка UTF-8, разделитель `;`):

| Поле | Обязательно | Описание |
|---|---|---|
| `id` | да | Уникальный идентификатор (`d1`, `d2`…) |
| `name` | да | Название, напр. «ВРД [станция]» |
| `operator` | нет | Владелец / оператор депо |
| `esr` | желательно | Код ЕСР станции примыкания — по нему депо связывается со станцией из справочника |
| `lat`, `lon` | желательно | Координаты депо (десятичные градусы, точка). Если пусто — берутся координаты станции по `esr` |
| `note` | нет | Примечание, показывается в карточке |

Нужно хотя бы одно из двух: координаты **или** код ЕСР станции. Записи без того и другого пропускаются с предупреждением в консоли.

## 4. Задачи для внедрения в `rws1520.html`

Выполнять по порядку. Номера блоков — из `depots-layer.js`.

1. **Данные.** Сконвертировать `depots.csv` в массив `DEPOTS` (блок 1) и встроить в файл так же, как встроены данные станций. `lat`/`lon` — числа или `null`, `esr` — строкой, как в справочнике.
2. **Код слоя.** Вставить содержимое `depots-layer.js` в основной `<script>` после объявления `BY_ESR`, `W`, `state` и после создания `map` и всплывашки `tip` (блоки 1–8 целиком; комментарии с инструкциями можно удалить после выполнения шагов ниже).
3. **Подключение слоя.** В конце функции `addStationLayers()` (после `addWagonLayers(); applyModeStyling();`) добавить вызов `addDepotLayers(dark);` — переменная `dark` там уже есть. Слой автоматически пересоздаётся при смене подложки, потому что `addStationLayers` вызывается на `style.load`.
4. **Клик.** В обработчике `map.on("click", e => {...})` сразу после `const pad = 6, p = e.point;` вставить две строки из комментария в блоке 5 — клик по депо обрабатывается раньше вагонов и станций.
5. **Подписи и бейдж.** Первой строкой в `updateLabels()` вызвать `updateDepotMarkers();` (блок 6).
6. **Переключатель.** В `#layersPop` после переключателя «Тарифные участки ТР №4» добавить:
   ```html
   <h3>Объекты</h3>
   <label class="switch-row" style="padding:2px 4px 12px">Вагоноремонтные депо <span class="switch"><input type="checkbox" id="depotsToggle"><span></span></span></label>
   ```
   Обработчик — блок 7 (уже в `depots-layer.js`).
7. **Легенда.** В `renderLegend()`, в ветке станций, сразу после строки `$("legendItems").innerHTML = items.map(...).join("");` добавить:
   `if (showDepots && DEPOTS.length) $("legendItems").insertAdjacentHTML("beforeend", depotLegendItem());`
8. **CSS.** Добавить в `<style>`:
   ```css
   .legend-item .dot-depot { border-radius: 3px; background: var(--text); box-shadow: 0 0 0 1.5px var(--panel-solid); }
   .depot-label { display: flex; align-items: center; gap: 6px; pointer-events: none; }
   .depot-badge { font-size: 11px; font-weight: 700; line-height: 16px; padding: 0 6px; border-radius: 999px;
     background: var(--data-strong, #C2410C); color: #fff; box-shadow: 0 0 0 1.5px var(--point-stroke, #fff); }
   .depot-name { font-size: 12px; font-weight: 600; color: var(--text); white-space: nowrap;
     text-shadow: 0 0 3px var(--label-halo), 0 0 3px var(--label-halo), 0 0 3px var(--label-halo); }
   .depot-card-t { font-size: 14px; font-weight: 650; margin-bottom: 4px; }
   .depot-card-m { font-size: 12px; color: var(--muted); margin-top: 4px; }
   ```
9. **Проверка.**
   - На светлой, тёмной подложке и спутнике депо видны и отличаются от станций на zoom 4, 7 и 11.
   - Клик по депо открывает карточку, кнопка станции выбирает станцию; клик рядом — по-прежнему выбирает станцию.
   - Переключатель скрывает значки, пунктир, подписи и строку легенды и запоминается после перезагрузки.
   - После смены подложки слой депо на месте, в консоли нет ошибок `Image "depot-…" could not be loaded` и `Layer "depots" already exists`.
   - На вкладке «Вагоны» с загруженными данными у депо, на станции которых есть записи, появляется оранжевый бейдж.
