# Регламент обновления RWS 1520

## Что и когда обновлять

| Что | Периодичность | Как |
|---|---|---|
| Сверка координат со свежим OpenStreetMap и Викиданными, поиск станций без координат по названию | **ежемесячно, 1-го числа** | автоматически: плановая задача Claude Code открывает PR с отчётом |
| ТР №4 (книги 1–3) | при выходе новой редакции | файлы кладутся в `data/raw/`, затем промт ниже |
| Справочник ЕСР, АСУ «Экспресс», перекодировка Крыма | по мере поступления новых файлов | то же |
| Предприятия ремонта (СЖА 1001 17, справочник кодов депо) | при новой редакции или новых кодах в дислокации | новые файлы в `data/raw/`, `parse_sja.py` (для PDF), `build_depots.py`; ненайденные — в `depots_manual.csv` |
| Граф сети для расстояний, главные магистрали | после обновления ТР №4 или справочника | `build_rail_graph.py` (после `build_stations.py`), затем `build_mainlines.py` |
| Дашборд, брендбук | по задачам | вручную |

Номер версии — по правилам из `README.md`: обновление данных — мелкая доработка (+0.1).
Ничего не попадает в `main` без проверки человеком: автоматическое обновление только открывает PR.

## Промт ежемесячного обновления

Вставьте в новую сессию Claude Code с этим репозиторием (так же его выполняет плановая задача):

```text
Ежемесячное обновление справочника RWS 1520 по регламенту UPDATING.md.

1. Работай от свежей ветки main. Если в репозитории нет scripts/fetch_sources.py или scripts/verify_sources.py —
   остановись и сообщи: обновление по этому регламенту невозможно.
2. Сохрани для сравнения data/output/stations.csv, data/output/verification.json и data/raw/sources_meta.json.
3. Выгрузи источники: python3 scripts/fetch_sources.py. Overpass перебирает зеркала; при 429 от Викиданных скрипт
   ждёт сам. Если источники недоступны после всех попыток — остановись и сообщи, какие адреса не отвечают
   (возможно, нужно разрешить их в настройках сетевого доступа окружения). Не подменяй данные старыми.
4. Пересобери: python3 scripts/build_stations.py, python3 scripts/build_depots.py, python3 scripts/build_rail_graph.py, python3 scripts/build_mainlines.py,
   затем python3 scripts/build_dashboard.py.
5. Сравни с сохранённым:
   - объекты OSM и элементы Викиданных: было → стало;
   - итоги сверки (verification.json): подтверждено, уточнено, заменено, добавлено, расхождения;
   - сколько кодов поменяли координаты (больше 0,5 км), класс и источник; без координат: было → стало;
   - новые коды в review_coordinates.csv.
6. Стоп-условия — не публикуй, а опиши ситуацию и спроси:
   - объектов OSM или элементов Викиданных стало меньше на 5% и больше (сбой выгрузки);
   - сдвинулось больше 1% точек класса A или больше 300 кодов в сумме;
   - число расхождений выросло больше чем на 50%;
   - сборка или проверки падают.
7. Если всё в норме: подними версию в VERSION на +0.1 (после x.9 — следующая целая), допиши CHANGELOG.md
   (раздел «Ежемесячное обновление данных <дата>» с цифрами из шага 5), пересобери дашборд под новой версией,
   закоммить и открой PR в main. В описании PR — таблица «было → стало», 10 самых больших сдвигов
   (код, станция, км, причина) и новые расхождения для ручной проверки. Не мерджи сам.
```

## Обновление после новых исходных файлов (ТР №4, ЕСР, Экспресс)

```text
Обновление справочника RWS 1520 по регламенту UPDATING.md: в data/raw/ новые файлы <перечислить>.
Посмотри, что изменилось в формате файлов, при необходимости поправь загрузчики (scripts/tr4_2026.py,
scripts/extra_sources.py, scripts/build_stations.py), затем выполни шаги 2–7 ежемесячного промта.
В отчёте отдельно — что дали новые файлы: новые и исключённые коды, переименования, изменения участков.
```

## Если что-то пошло не так

| Симптом | Что делать |
|---|---|
| Overpass: обрыв соединения или таймаут | скрипт сам перебирает зеркала; если не отвечает ни одно — повторить позже |
| Викиданные: HTTP 429 | скрипт ждёт и повторяет; при повторных отказах — запустить позже |
| `CONNECT tunnel failed, 403` | адрес не разрешён в сетевых настройках окружения — добавить в «Разрешённые домены» |
| Резко изменились цифры | не публиковать; сравнить выгрузки `data/raw/*` с прошлыми в истории git |

Нужные адреса для сетевого доступа: `maps.mail.ru`, `overpass-api.de`, `overpass.kumi.systems`,
`query.wikidata.org`, `www.wikidata.org` (и для сверки по карте: `nominatim.openstreetmap.org`,
`api.openstreetmap.org`, `tile.openstreetmap.org`).
